# Loomoon Canvas 交互系统设计

日期：2026-07-26

## 1. 目标与范围

本规格将 Loomoon Canvas 从多个互相重叠的局部状态，重构为具备明确工具状态、对象焦点、生成器节点和对象图层面板的无限画布。

本阶段交付：

- 选择、小手、画笔、形状、文字五种互斥编辑工具。
- 图片生成器与视频生成器入口及其正式画布节点。
- 与生成器节点绑定的提示词表单、参考图、模型和画幅配置。
- 左下角对象图层面板：选择、显示、锁定、排序、删除。
- 画布与图层面板的双向选择同步。
- 桌面快捷键、临时小手、撤销重做与移动端触控规则。
- 将画笔路径、生成器配置、可见性和层级写入可持久化画布数据。

本阶段不引入 Miro 式命名图层组。一个画布对象对应一个图层项，现有 `groupId` 继续承担对象分组。命名图层组可在后续数据迁移中增加。

## 2. 设计原则

1. 同一时刻只有一个顶级工具拥有指针事件。
2. 工具模式和对象选择是两类状态：切换工具保留现有选择；完成创建时改为选中新对象；只有点击空白或执行第二级 `Escape` 才清空选择。
3. 画布节点是持久化业务实体；悬停、按下、拖拽中等瞬时状态不写入项目数据。
4. 生成器不是浮在页面上的临时表单，而是带配置和生命周期的正式画布节点。
5. 图层面板中的排序就是画布渲染顺序，数组底部为画布后方，数组顶部为画布前方。
6. 所有可能冲突的输入都按明确优先级分派，不依赖组件各自拦截事件。

## 3. 状态架构

### 3.1 顶级工具

```ts
type CanvasTool =
  | "select"
  | "hand"
  | "draw"
  | "shape"
  | "text"
  | "image-generator"
  | "video-generator";
```

选择、手型和画笔属于持续工具。形状、文字和生成器属于创建工具；完成一次创建后默认返回 `select`。未来可通过“连续创建”开关保持创建工具，本阶段不实现该开关。

### 3.2 工具子状态

```ts
type CanvasInteraction =
  | { kind: "idle" }
  | { kind: "pressing-canvas"; origin: Point }
  | { kind: "pressing-node"; nodeId: string; origin: Point }
  | { kind: "panning"; origin: Point; initialCamera: Camera }
  | { kind: "marquee"; origin: Point; current: Point }
  | { kind: "moving-selection"; origin: Point; snapshots: NodeSnapshot[] }
  | { kind: "drawing"; strokeId: string }
  | { kind: "creating-shape"; nodeId: string; origin: Point }
  | { kind: "editing-text"; nodeId: string }
  | { kind: "reordering-layer"; nodeId: string };
```

工具切换必须先结束当前子状态：取消未完成形状、提交有效画笔路径、结束文字编辑或停止画布平移。

### 3.3 临时小手

- 按住 `Space` 时记录当前工具，并临时切换到 `hand`。
- 松开 `Space` 恢复此前工具。
- 正在编辑文字或输入生成提示词时，空格只输入字符，不切换工具。
- 正在拖动、绘制或创建形状时按空格不改变当前手势。

## 4. 指针事件分派

所有指针事件先进入单一 Canvas 控制器，再根据当前工具和命中目标分派。

### 4.1 选择工具

- 点击对象：选择该对象。
- `Shift + 点击`：切换对象的多选状态。
- 拖动已选对象：移动当前选择；锁定对象不移动。
- 拖动未选对象：先将其设为唯一选择，再移动。
- 拖动画布空白：开始框选，不平移画布。
- 点击空白：清空选择。
- 双击文字：进入文字编辑。
- 双击图片：保留给裁剪或局部编辑，本阶段不执行隐式操作。

### 4.2 小手工具

- 在空白、对象、锁定对象或生成器上按下并拖动，均只平移相机。
- 不改变选择，不触发对象拖动，不打开生成器表单。
- 单击对象不改变选择。

### 4.3 画笔工具

- 在任何命中目标上按下都开始新路径；底层图片和对象不接收事件。
- 指针移动追加经过缩放和相机变换后的画布坐标。
- 指针抬起后：少于两个有效采样点则丢弃，否则保存为正式路径节点。
- 完成路径后保持画笔工具，便于连续绘制。
- `Esc` 取消当前未完成路径，并保持画笔工具。

### 4.4 形状工具

- 用户先从形状菜单选择具体形状类型。
- 在画布拖动产生实时预览；不足最小尺寸时按默认尺寸创建。
- 创建完成后选中新形状并返回选择工具。
- 形状创建过程中对象不接收选择和移动事件。

### 4.5 文字工具

- 点击位置创建文字节点并立即进入原位编辑。
- 点击已有文字时直接编辑该文字，不额外创建节点。
- `Enter` 根据编辑器约定换行，`Meta/Ctrl + Enter` 完成编辑，`Esc` 取消本次编辑。
- 完成或取消后返回选择工具。

## 5. 键盘、滚轮和触控板

- `V`：选择工具。
- `H`：小手工具。
- `P`：画笔工具。
- `T`：文字工具。
- `R`：矩形工具。
- `Space`：临时小手。
- `Escape`：依次取消当前手势、退出文字编辑、清空选择。
- `Delete/Backspace`：删除未锁定的选择对象。
- `Meta/Ctrl + Z`：撤销。
- `Meta/Ctrl + Shift + Z`：重做。
- `Meta/Ctrl + D`：复制选择。
- 触控板双指移动：平移相机。
- `Meta/Ctrl + 滚轮` 或捏合：以指针位置为中心缩放。
- 普通鼠标滚轮默认平移；不因当前工具不同而改变。
- 当焦点位于文本框、下拉菜单或生成器表单时，不执行工具快捷键和删除命令。

## 6. Canvas 节点模型

扩展节点类型：

```ts
type CanvasNodeType =
  | "image"
  | "text"
  | "shape"
  | "path"
  | "artboard"
  | "image-generator"
  | "video-generator"
  | "generation-placeholder";
```

所有节点共有：

```ts
interface CanvasNodeBase {
  id: string;
  type: CanvasNodeType;
  x: number;
  y: number;
  width: number;
  height: number;
  rotation: number;
  name: string;
  visible: boolean;
  locked: boolean;
  groupId?: string;
}
```

路径节点保存画布坐标点、颜色、宽度、透明度和线帽。生成器节点保存独立配置，不再依赖全局 `generatorKind` 或全局提示词输入。

旧节点迁移时补充默认值：`rotation = 0`、`visible = true`、`locked = false`，名称根据类型和序号生成。

## 7. 生成器节点与锁定表单

### 7.1 创建与焦点

- 点击图片或视频生成器工具后，在当前视口中央创建一个生成器节点。
- 创建后返回选择工具，并把新节点设为唯一选择和焦点节点。
- 只有“唯一选择且该对象是生成器”时显示下方表单。
- 选择其他对象、清空选择或删除生成器时，表单关闭。
- 再次选中生成器时，从节点配置恢复表单内容。

### 7.2 锚定行为

- 表单的视觉位置由生成器节点的屏幕包围盒计算：水平居中，位于节点下方固定间距。
- 平移、缩放、移动或调整生成器尺寸时，表单实时跟随。
- 表单是 HTML Overlay，不随舞台缩放，保持可读尺寸。
- 节点接近视口底部时，表单翻转到节点上方；空间仍不足时固定在视口安全区，并用视觉连接提示关联对象。
- 表单处于焦点时，画布快捷键暂停，但 `Escape` 仍可退出表单焦点。

### 7.3 表单字段

- 提示词：必填，多行输入，保存在节点草稿配置中。
- 参考图：支持本地上传和从画布当前选择中添加；显示缩略图、来源和移除按钮。
- 模型：按图片/视频类型过滤，展示模型名称、版本、能力和预计消耗。
- 画幅：图片默认 `1:1`，视频默认 `16:9`。
- 输出数量：图片默认 4，视频默认 1。
- 高级设置：后续可扩展 seed、风格强度、参考强度；本阶段数据结构预留但界面不强制展示。
- 生成按钮：提示词无效、模型不可用或任务提交中时禁用。

Adobe Firefly 的成熟生成流程同样将提示词、参考图、模型和画幅组成一次生成配置；本实现沿用这一信息架构，但视觉保持星流参考。

### 7.4 生成生命周期

```ts
type GeneratorStatus =
  | "draft"
  | "submitting"
  | "running"
  | "succeeded"
  | "partially-failed"
  | "failed"
  | "cancelled";
```

- 提交后保留生成器节点，并在其关联区域添加占位结果节点。
- 运行中允许平移画布和移动整个生成器，但不允许重复提交同一个任务。
- 删除运行中的生成器必须二次确认，并说明是否同时取消任务和删除已完成结果。
- 成功结果成为独立图片/视频节点，并通过 `sourceGeneratorId` 追溯生成器。
- 失败保留提示词和配置，允许重试。

## 8. 对象图层面板

### 8.1 入口与位置

- 左下角显示图层图标和当前可见对象数量。
- 点击后在入口上方打开浮动面板；再次点击、点击面板外或按 `Escape` 关闭。
- 桌面面板宽约 280px，最大高度受视口限制，内容区独立滚动。
- 移动端从底部打开半屏抽屉，避免与底部工具栏重叠。

### 8.2 列表语义

- 每个 Canvas 节点对应一个图层项。
- 面板顶部表示画布最前方，底部表示最后方。
- 每项显示：拖拽手柄、类型图标、缩略图或类型预览、名称、可见性、锁定状态和更多菜单。
- 点击图层项选择对应对象，并把画布视口滚动到对象可见区域；`Shift` 支持多选。
- 画布选择变化时，面板同步选中并滚动到首个选中项。

### 8.3 图层操作

- 拖拽排序：改变节点数组顺序并立即更新覆盖关系。
- 显示/隐藏：隐藏节点不渲染、不命中、不框选、不导出、不进入 Agent 画布选择。
- 锁定/解锁：锁定节点可被选择和查看，但不能移动、缩放、编辑或删除。
- 删除：未锁定节点立即删除并支持撤销；锁定节点显示不可删除反馈。
- 重命名：双击名称或从更多菜单进入编辑。
- 复制：从更多菜单复制节点并放在原节点上方。
- 置顶/置底：作为拖拽排序的快捷操作保留在更多菜单。

### 8.4 重叠与选择

- 画布点击重叠区域默认选择最前方可见、未穿透的节点。
- `Meta/Ctrl + 点击` 在命中栈中循环选择，避免只能通过图层面板选择底层对象。
- 锁定节点仍参与命中；再次循环可以选择其下方节点。

## 9. 撤销、持久化与同步

以下操作进入统一历史记录：

- 创建、删除、移动、缩放、旋转节点。
- 画笔路径创建。
- 图层排序、显示、锁定、重命名。
- 生成器配置修改和参考图增删。
- 分组与取消分组。

相机平移、缩放、工具切换、面板开关、悬停和表单焦点不进入项目历史。

历史记录采用可逆 Canvas 操作而不是保存整个节点数组。服务端事件到达时，以节点版本或操作版本合并，避免当前实现中空画布更新覆盖本地状态的问题。

## 10. Agent 集成

- 只有可见图片/视频节点可以加入 Agent 选择附件。
- 锁定不阻止把节点作为 Agent 上下文。
- 生成器节点本身不作为图片附件，但其提示词、模型、状态可以作为结构化上下文。
- Agent 生成的新节点进入当前最高层，并关联来源消息和生成任务。
- 从 Agent 请求修改选中图片时，提交时冻结节点 ID 快照；之后用户改变选择不影响已提交任务。

## 11. 移动端规则

- 单指行为由当前工具决定：选择移动对象、小手平移、画笔绘制。
- 双指始终负责平移和缩放，并临时压过当前工具，不能留下路径或移动对象。
- 长按对象打开上下文菜单，不作为拖动开始。
- 工具栏横向滚动，持续工具固定在前，生成器放在后。
- 图层面板是底部抽屉；拖拽排序提供明显手柄，并支持“上移/下移”作为无障碍替代。
- 生成器表单以底部工作台呈现，同时高亮关联生成器节点；不强制显示在节点物理下方。

## 12. 错误和边界处理

- 上传参考图校验格式、大小和数量，失败不得丢失已有提示词。
- 模型切换导致已有配置不兼容时，明确指出被重置的字段。
- 隐藏或锁定多选对象时，仅对允许操作的对象生效，并报告跳过数量。
- 删除包含运行任务的生成器必须确认；普通对象删除可直接撤销。
- 网络保存失败时保留本地操作队列，显示未同步状态并允许重试。
- 项目在其他页面更新时，不覆盖当前未提交手势；手势结束后再合并远端操作。

## 13. 组件和模块边界

- `canvas-tool-state.ts`：顶级工具、子状态和快捷键转换，纯函数可测试。
- `canvas-controller.ts`：统一接收指针/键盘事件并分派操作。
- `canvas-node.ts`：节点联合类型、迁移和公共规则。
- `canvas-operations.ts`：创建、删除、排序、显示、锁定和历史操作。
- `canvas-viewport.ts`：相机平移、缩放、坐标转换和聚焦节点。
- `generator-node.ts`：生成器配置、校验和生命周期。
- `generator-overlay.tsx`：锚定表单及参考图、模型选择界面。
- `layers-panel.tsx`：对象列表及排序、显示、锁定、删除操作。
- `canvas-stage.tsx`：Konva 渲染和命中目标转换，不直接决定业务行为。
- `app.tsx`：负责项目装载、服务端同步和模块编排，不继续累积工具细节。

## 14. 测试策略

### 14.1 单元测试

- 每个工具只处理属于自己的指针事件。
- Hand 在图片上拖动只改变相机，不改变节点坐标和选择。
- Draw 在图片上绘制只创建路径，不移动图片。
- 创建工具完成后返回 Select。
- 临时 Hand 松开后恢复原工具。
- 生成器表单显示条件、锚定方向和字段校验。
- 图层排序、显示、锁定、删除及撤销。
- 隐藏节点不进入命中、框选、导出和 Agent 附件。

### 14.2 组件测试

- 工具栏只存在一个激活工具。
- 图层面板与画布选择双向同步。
- 生成器失焦后表单关闭，再选择时草稿恢复。
- 表单输入时快捷键不误触发工具或删除。
- 移动端图层抽屉和生成器工作台不遮挡主要操作。

### 14.3 浏览器验收

- 在图片上分别使用 Select、Hand 和 Draw，验证三种行为互不串扰。
- 创建图片生成器，移动、缩放和切换选择，验证表单锚定和状态恢复。
- 上传参考图、选择模型和画幅，提交 Mock 任务并验证状态变化。
- 图层面板拖动排序后验证实际覆盖关系；隐藏、锁定、删除后验证画布同步。
- 验证 `Space` 临时小手、`Esc`、删除和撤销重做。
- 桌面和移动端分别截图，与星流参考状态并排比较。

## 15. 验收条件

1. Select、Hand、Draw 在对象上的拖动结果完全互斥。
2. 任一时刻工具栏只有一个持续激活工具。
3. 生成器表单只跟随当前唯一选中的生成器节点，配置可恢复且可提交。
4. 图层面板完整列出对象，排序与画布覆盖关系一致。
5. 隐藏、锁定和删除规则在画布、图层、导出和 Agent 上保持一致。
6. 所有持久化行为可撤销重做，并通过刷新恢复。
7. 移动端触控不因单指/双指冲突误移动对象或留下路径。
8. 自动化测试、类型检查、生产构建和浏览器交互验收全部通过。
