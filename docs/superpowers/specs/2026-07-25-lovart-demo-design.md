# Lovart 通用视觉创作 Demo 产品需求与验收规格

**日期：** 2026-07-25  
**状态：** 已确认  
**产品方向：** 垂直闭环 Demo  
**技术选型：** Konva + Pi Agent Core + 百炼模型服务

## 1. 产品目标

用户通过自然语言描述视觉创作需求。Agent 理解需求并提出两个视觉方向；用户确认计划后，系统调用百炼生成共四张候选图片并自动组织到无限画布。用户可以选择一张或圈选多张图片，让 Agent 分析、比较、参考生成、批量修改或局部修改，最后下载单图或导出画板。

标准演示应让首次使用者在 10 分钟内完成：

1. 创建项目；
2. 输入视觉需求；
3. 查看、调整并确认 Agent 创作计划；
4. 获得两个方向、共四张候选图；
5. 在画布中比较和整理结果；
6. 使用 Agent 完成一次图片修改；
7. 完成一次框选区域局部修改；
8. 下载原图或导出画板。

## 2. 范围

### 2.1 首版包含

- 单用户登录、多项目管理和用户间数据隔离；
- Konva 无限画布；
- 图片、文字、画板、分组和生成占位节点；
- 选择、框选、多选、移动、缩放、复制、删除、分组、层级调整；
- 撤销与重做；
- Pi Agent Core 流式对话和受限工具调用；
- 创意需求分析、两个视觉方向、计划调整和执行确认；
- 百炼大语言、多模态、文生图、图生图和局部图片修改；
- 单图整图重绘、参考图改版、局部修改；
- 多图分析、多图参考、多图融合和批量修改；
- 图片生成任务状态、取消、失败与重试；
- 项目自动保存、刷新恢复和生成历史；
- 单图原始文件下载；
- 画板 PNG/JPEG 导出。

### 2.2 首版不包含

- 视频、音频和时间线；
- ComfyUI；
- 多人实时协作；
- Photoshop 式专业图像编辑；
- PSD、SVG、PDF 和完整项目包导出；
- 计费、套餐和商业运营后台；
- 大规模生产级高可用部署；
- Agent 任意文件系统、Shell 或外部网络访问；
- 第三方 Pi 扩展和动态工具安装；
- 手机端、平板端和完整 Safari 兼容。

### 2.3 界面与布局原则

工作区在结构和交互上高度参考 Lovart ChatCanvas，但使用独立品牌视觉，不复制其品牌标识、颜色、字体、图标和装饰样式。

桌面工作区采用：

- 顶部项目栏：品牌入口、项目名称、保存状态、历史、分享和导出；
- 左侧紧凑工具栏：选择、插入、文字、画板、绘制和视图工具；
- 中央无限画布：占据主要可视空间，承载需求、方向、图片和画板；
- 右侧可折叠 Agent 面板：承载对话、计划、确认、工具状态和任务进度；
- 画布角落缩放控件：缩小、比例、放大和适应内容；
- 对象上下文工具条：选中图片后就近展示比较、作为参考、Agent 修改、下载和更多操作；
- Agent 输入框选择区：圈选多图后显示数量和缩略图，可逐张移除。

布局验收：

- 1440×900 下中央画布始终是最大区域；
- 默认 Agent 面板宽度约 360–400 px，可折叠和恢复；
- 左侧工具栏不超过 64 px；
- 顶栏不超过 64 px；
- Agent 流式输出或图片任务更新时不阻塞画布；
- 上下文工具条跟随选择对象，并避免超出视口；
- 多图选择快照在输入框中清晰可见；
- 窗口宽度不足时允许折叠 Agent，而不是压缩画布至不可用；
- 所有视觉 Token 使用自有设计系统，界面不得出现 Lovart 商标或品牌素材。

## 3. 核心用户流程

```text
登录并创建项目
→ 输入创作需求和可选参考图
→ Agent 输出两个视觉方向
→ 用户调整并确认计划
→ 系统并行生成四张候选图
→ 自动按方向布置到画布
→ 用户单选或圈选多张图片与 Agent 对话
→ Agent 判断分析、参考、单图修改、批量修改或局部修改
→ 用户确认有成本的图片操作
→ 新结果回填画布并建立来源关系
→ 用户整理画板并导出
```

## 4. 功能需求与验收标准

### FR-01 用户登录与隔离

**需求**

- 使用账号和密码登录；
- 登录状态在刷新后保持；
- 未登录用户不能访问项目和资产；
- 用户只能访问自己的项目、消息、任务和资产。

**验收**

- 正确凭据进入项目列表，错误凭据显示通用错误；
- Token 失效后跳转登录页，退出后旧 Token 失效；
- 替换请求中的项目、节点或资产 ID 不能越权访问；
- 越权错误不暴露目标资源是否存在。

### FR-02 项目管理

**需求**

- 创建、重命名、打开和删除项目；
- 展示封面、更新时间和项目状态；
- 画布自动保存；
- 删除项目需要二次确认。

**验收**

- 创建后 2 秒内打开空白画布；
- 重命名、节点位置、尺寸和内容刷新后保持；
- 删除确认前不移除项目；
- 删除后立即从用户界面消失，关联资产按延迟清理策略处理。

### FR-03 创作需求与上下文

**需求**

- Agent 面板接收自然语言需求；
- 支持上传最多 3 张初始参考图；
- Agent 获取项目、画布选择和参考图上下文；
- 输入和 Agent 响应不阻塞画布操作。

**验收**

- 提交后 10 秒内出现首个流式响应或处理状态；
- 空输入不可提交；
- 支持 JPG、PNG、WebP，单文件不超过 20 MB；
- 上传项显示缩略图并可删除；
- 非法格式、超限或无法解码的文件被拒绝；
- 提交时保存选择快照，后续选择变化不影响已提交消息。

### FR-04 Agent 创意计划

**需求**

Agent 生成结构化计划，包含：

- 需求摘要；
- 目标受众或使用场景；
- 两个视觉方向；
- 每个方向的风格、构图、色彩和生成意图；
- 每个方向两张候选图；
- 预计执行内容和成本提示；
- “确认生成”和“要求调整”操作。

**验收**

- 每次计划准确包含两个方向；
- 用户确认前不得调用付费图片工具；
- 调整计划不触发图片生成；
- 确认后记录计划版本、确认用户和确认时间；
- 后端校验确认状态，不能通过伪造前端请求绕过。

### FR-05 批量候选图生成

**需求**

- 两个方向分别生成两张候选图；
- 四个任务允许并行，但每用户最多同时运行两个；
- 保存方向、Prompt、模型、尺寸、任务和资产信息；
- 结果自动加入画布。

**验收**

- 正常执行准确创建四个任务；
- 每个方向对应两张结果；
- 节点显示排队、生成中、成功、失败或取消状态；
- 单任务失败不影响其他任务；
- 失败项可单独重试且不重复成功任务；
- 重复回调或轮询结果不产生重复资产或节点；
- 原图保存于服务端资产存储，不依赖百炼临时地址。

### FR-06 自动画布布局

**需求**

- 创建一个总需求区和两个创意方向区；
- 每个方向包含说明文字及两张候选图；
- 新内容不覆盖或移动已有节点。

**验收**

- 两个方向视觉分区明确；
- 说明文字与候选图关系明确；
- 节点无非预期重叠；
- 新内容出现在当前可视区域附近，或自动定位到新内容；
- 自动创建与布局作为一个撤销事务。

### FR-07 执行状态

**需求**

Agent 面板显示分析中、等待确认、生成进度、部分失败、完成和取消状态。

**验收**

- Agent 文本流和图片任务进度独立显示；
- 刷新后从服务端恢复状态；
- 用户可取消未完成批次；
- 取消后不再提交新任务，已完成图片保留；
- 超时或服务异常不会永久停留在加载状态。

### FR-08 单图 Agent 修改

**需求**

- 选中图片后，Agent 获取图片、原始提示词、创意方向和版本历史；
- Agent 判断整图重绘、参考改版或局部修改；
- 执行前展示对象、类型和修改摘要并要求确认；
- 修改产生新资产和新节点，不覆盖原图。

**验收**

- 单选时明确显示修改对象；
- 未选图时要求用户选择；
- 未确认前不调用图片工具；
- 新结果记录来源图片、指令和生成参数；
- 新结果默认放在原图附近并可继续修改；
- 任意版本可追溯到初始图片。

### FR-09 多图圈选上下文

**需求**

- 支持框选或 Shift 多选最多 8 张图片；
- Agent 获取选择快照、原始资产、生成参数、来源和所属方向；
- Agent 自行判断多图分析、比较、作为参考、指定主图、批量修改或融合生成；
- 输入区显示选中数量和缩略图，用户可逐张移除。

**验收**

- 提交后固定选择快照；
- Agent 回复说明识别出的主图、参考图和操作范围；
- 分析、比较和总结不调用图片生成工具；
- 明确复数指令可判定为批量修改；
- 范围不明确时必须询问，不得静默批量执行；
- 判断结果和选择快照写入操作记录。

### FR-10 批量图片修改

**需求**

- 对每张目标图片建立独立任务；
- 执行前展示目标数量、修改摘要和预计任务数；
- 一次确认后批量执行；
- 每个结果分别关联自身来源图片。

**验收**

- 未确认不创建任务；
- N 张目标图准确产生 N 个任务；
- 单任务失败不影响其他任务；
- 支持失败项单独重试；
- 整批结果的节点创建和布局作为一次撤销事务；
- 取消后不提交待执行项，已完成结果保留。

### FR-11 多图参考与融合

**需求**

- 圈选图片可作为构图、色彩、主体或材质参考；
- Agent 说明各参考图的用途；
- 新图片不覆盖任何参考图；
- 百炼参考图数量不足时，在执行前说明筛选或合成策略。

**验收**

- 确认前展示实际使用的参考图及用途；
- 不静默丢弃超过模型限制的参考图；
- 新资产记录实际采用的全部参考资产；
- 新节点与参考图片建立来源关系；
- 模型不支持时明确提示减少参考图或使用拼图参考策略。

### FR-12 区域图片修改

**需求**

- 用户在图片上绘制一个或多个修改区域；
- 前端保留完整像素蒙版，并计算最多两个外接边界框；
- 边界框以原始图片绝对像素坐标保存；
- Agent 默认提交原图、边界框和修改指令给 Wan 2.7；
- 返回完整修改结果。

**验收**

- 不同画布缩放下区域对应同一图像位置；
- 图片移动或缩放后边界框仍准确；
- 空蒙版不能提交，越界部分被裁剪；
- 提交前显示修改范围；
- 默认保持原图尺寸和比例；
- 结果保存原图、完整蒙版、实际边界框和指令来源；
- 明确提示当前模型按边界框编辑，不能承诺框内未涂抹区域完全不变；
- 固定用例通过：替换物体、修改颜色或材质、移除元素并补全背景。

精确像素蒙版作为可选增强能力保留。仅当 `wanx2.1-imageedit` 在目标百炼地域、账号和效果验证中通过时启用；未来接入 ComfyUI 时沿用同一 `mask_inpaint` 业务接口。

### FR-13 Agent 工具可见性与约束

**需求**

- 以业务语言显示 Agent 动作；
- 不暴露系统提示词、密钥、原始推理或内部异常栈；
- 所有副作用工具接受服务端权限、Schema、幂等和确认校验。

**验收**

- 前端显示“分析画布”“提交局部修改”等状态；
- 重复确认只执行一次；
- 每次调用记录用户、项目、Agent Run、工具、目标和结果；
- Agent 只能操作当前用户有权限的对象。

### FR-14 画布导航与选择

**需求**

- 平移、滚轮缩放、适应内容和回到 100%；
- 单选、框选和 Shift 多选；
- 移动、缩放、复制、删除、锁定；
- 快捷键和右键菜单。

**验收**

- 缩放以指针或指定中心为基准并有合理范围；
- 多选移动保持相对位置；
- 锁定节点不可移动、缩放或删除；
- 复制产生新节点 ID，不复用任务 ID；
- 文字输入聚焦时 Delete/Backspace 不误删节点。

### FR-15 节点、分组和来源

**需求**

- 图片节点支持结果和任务占位；
- 文字节点支持基础文字、字号、颜色和对齐；
- 画板定义尺寸、背景和导出区域；
- 支持分组、取消分组和层级调整；
- 生成与修改结果可显示来源连线。

**验收**

- 图片失败显示可重试占位；
- 文字和层级刷新后保持；
- 画板支持预设和自定义尺寸；
- 分组移动保持相对位置，取消分组不改变视觉位置；
- 删除来源连线不删除图片；
- 来源图片删除后派生结果保留并标记来源缺失。

### FR-16 撤销与重做

**需求**

- 移动、缩放、创建、删除、分组和层级操作可撤销重做；
- Agent 批量画布操作为一个事务；
- 撤销画布节点不自动撤销已发生的模型费用。

**验收**

- 操作按正确顺序撤销和重做；
- Agent 自动布局可一次撤销；
- 撤销生成结果时提示远程任务已产生；
- 撤销后执行新操作清理无效重做栈；
- 刷新后不要求恢复完整撤销历史。

### FR-17 自动保存与任务恢复

**需求**

- 画布操作防抖保存；
- Agent 操作和生成结果立即持久化；
- 保存失败显示未同步并自动重试；
- 文档使用版本号防止旧数据覆盖新数据。

**验收**

- 停止编辑后 2 秒内发起保存；
- 断网时显示未同步，恢复后自动重试；
- 旧版本写入被拒绝并返回冲突；
- 图片完成时用户即使离开页面，结果仍写入项目；
- 生成中刷新页面后能恢复任务状态。

### FR-18 生成历史

**需求**

- 展示项目内图片生成和修改记录；
- 包含缩略图、状态、类型、时间和来源；
- 历史结果可重新加入画布；
- 失败记录可重试。

**验收**

- 删除画布节点不删除历史资产；
- 同一资产重复加入画布使用不同节点 ID；
- 支持按状态和生成类型筛选；
- 重试创建新任务并保留失败记录；
- 用户不能查看其他用户历史。

### FR-19 下载与画板导出

**需求**

- 下载生成或修改后的原始图片；
- 画板导出 PNG/JPEG，支持 1× 和 2×；
- 导出可见图片和文字，不包含编辑控件、来源连线和任务 UI。

**验收**

- 单图下载不受画布缩放影响；
- 扩展名与 MIME 类型一致；
- 下载接口鉴权或使用短期签名地址；
- 导出尺寸等于画板尺寸乘倍率；
- 超出画板内容被裁切；
- PNG 可保留透明背景，JPEG 使用指定背景；
- 导出不阻塞或破坏画布。

## 5. 非功能需求

### 5.1 性能

| 指标 | 验收标准 |
|---|---|
| 首屏加载 | 正常网络 5 秒内进入项目页 |
| 打开项目 | 100 个节点以内 5 秒内可操作 |
| Agent 首次反馈 | 10 秒内出现流式内容或处理状态 |
| 本地画布反馈 | 常规操作原则上不超过 100 ms |
| 自动保存 | 停止操作后 2 秒内发起 |
| 并发用户 | 至少 5 个 |
| 单用户并行图片任务 | 最多 2 个，其余排队 |
| 单次多图上下文 | 最多 8 张 |

百炼生成耗时不设绝对上限，但必须持续显示真实任务状态。

### 5.2 稳定性

- Agent 对话、画布保存和图片任务解耦；
- 单任务异常不导致项目或服务进程不可用；
- 所有远程任务使用幂等键；
- 重复通知不产生重复资产；
- 后端重启后可恢复未完成任务查询；
- 超时、限流和非法响应映射为可操作错误。

### 5.3 安全

- 仅嵌入 Pi Agent Core；
- 不暴露 Shell、文件系统、任意 HTTP 或动态扩展工具；
- 所有工具校验用户、项目、资产、Schema、确认状态和幂等键；
- 百炼密钥仅存于服务端且不得写入日志；
- 上传执行格式、MIME、大小和图片解码校验；
- 高成本图片操作必须确认；
- 所有副作用工具写入审计记录。

### 5.4 可观测性

## 6. 系统与数据边界

核心领域对象：

```text
User
└── Project
    ├── CanvasDocument
    │   ├── CanvasNode
    │   └── NodeRelation
    ├── AgentSession
    │   └── AgentMessage
    │       └── AgentRun
    │           └── ToolCall
    └── GenerationTask
        └── Asset
```

- `CanvasDocument` 保存与 Konva 解耦的业务画布文档和版本；
- `CanvasNode` 首版包含 image、text、artboard、group、generation-placeholder；
- `Asset` 保存原图、缩略图、尺寸、格式、存储位置和来源；
- `AgentMessage` 保存消息提交时的 `selection_snapshot`；
- `GenerationTask` 保存类型、输入、状态、幂等键、结果和错误；
- `NodeRelation` 支持 generated_from、edited_from、referenced_by、belongs_to_direction。

Agent 可以分析需求与图片、生成计划、判断多图意图、选择受限工具、生成画布操作并解释结果。Agent 不得直接修改数据库、持久化任意 Konva JSON、绕过确认、访问任意网络或文件系统、永久删除资产或扩大批量范围。

## 7. 错误处理

| 场景 | 用户体验 | 系统行为 |
|---|---|---|
| 百炼限流 | 排队或稍后重试 | 有上限的指数退避 |
| 百炼鉴权失败 | 服务配置异常 | 不暴露密钥 |
| 图片生成失败 | 失败占位和重试 | 保留输入与失败任务 |
| Agent 输出格式错误 | 正在重新整理 | 最多自动纠正一次 |
| 工具参数非法 | 不执行并解释问题 | Schema 拒绝 |
| 自动保存失败 | 显示未同步 | 本地保留并重试 |
| 文档版本冲突 | 提示重新同步 | 拒绝旧版本覆盖 |
| 参考图丢失 | 要求重新选择 | 提交前终止 |
| 局部蒙版为空 | 禁止确认 | 不创建任务 |
| 批次取消 | 已完成项保留 | 不提交待执行项 |
| 页面刷新 | 恢复任务状态 | 从服务端重新订阅 |
| 多图意图不明确 | 要求明确范围 | 不调用付费工具 |

## 8. 端到端验收

### E2E-01 首次创作

创建项目，输入青柠气泡水广告需求，Agent 输出两个方向；用户调整其中一个方向并确认；系统生成四张图并自动布局；刷新页面。

**通过：** 确认前零图片任务，确认后准确四个；方向映射、布局、对话、图片和刷新恢复正确。

### E2E-02 单图重绘

选中一图，要求保留产品和主色并改为夜间音乐节风格，确认执行。

**通过：** 原图保留，新图位于附近并记录来源、指令和参数，可继续修改。

### E2E-03 多图分析

框选四图，要求比较并推荐社媒主视觉。

**通过：** Agent 引用图片完成比较，不创建任务、不修改画布，保存选择快照。

### E2E-04 多图参考

圈选三图，分别引用构图、颜色和材质生成新方向。

**通过：** 执行前说明各图用途；新结果记录实际参考并建立关系；不覆盖原图。

### E2E-05 批量修改

框选两图，明确要求分别将背景改为夜晚；其中一个任务模拟失败。

**通过：** 准确创建两个任务；一个失败不影响另一个；可单独重试；来源正确。

### E2E-06 意图澄清

框选三图，仅输入“把背景改成夜晚”。

**通过：** Agent 询问全部修改、指定主图或作为参考；澄清前零任务。

### E2E-07 区域修改

选择图片，涂抹或框选柠檬并要求替换为冰块。

**通过：** 完整蒙版和换算后的原图像素边界框准确；默认向 Wan 2.7 提交原图、边界框和指令；结果保持尺寸，并可追溯原图、蒙版、边界框和请求。

### E2E-08 画布编辑

移动、缩放、新建文字、分组、调整层级、撤销重做并刷新。

**通过：** 交互、历史顺序、文本输入保护和刷新恢复正确。

### E2E-09 画板导出

透明画板包含图片、文字、来源线和选中框，以 2× PNG 导出。

**通过：** 像素尺寸正确；只包含设计内容；透明背景保留；画布不受影响。

### E2E-10 断线恢复

生成中刷新并短暂断网后恢复。

**通过：** 后端任务持续；前端恢复状态与保存；无重复节点或资产。

### E2E-11 权限隔离

第二用户替换项目、节点、资产和下载标识，并通过 Prompt 请求其他用户数据。

**通过：** 全部拒绝；不泄露存在性；记录安全日志；原数据不变。

### E2E-12 百炼异常

分别模拟超时、限流、鉴权失败、非法结果和批量单项失败。

**通过：** 无永久加载；错误可理解；重试不重复成功项；不泄露密钥；项目始终可用。
