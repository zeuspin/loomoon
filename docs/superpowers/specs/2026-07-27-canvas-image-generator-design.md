# Loomoon 画布图像生成器设计

日期：2026-07-27

## 1. 目标

在现有无限画布中实现可真实调用百炼图像模型的生成器。交互参考 Lovart 的画布生成器，但沿用 Loomoon 的品牌、画布状态、Agent 活动流、资产存储和任务模型。

本期交付从生成器配置到真实图片回填画布的完整闭环：

- 大尺寸画布生成器面板；
- 参考图、提示词、模型、质量、尺寸、宽高比和输出数量配置；
- 多个真实图像模型切换；
- 复用 Agent 付费操作执行链路的可信直接提交；
- 排队、生成中、部分失败、失败、重试和刷新恢复；
- 结果资产持久化；
- 第一张结果原位替换生成器，其余结果自动排列；
- 为未来积分系统预留费用估算和预授权字段，但本期不扣费。

本期不实现视频生成器、积分账户、真实扣费、退款、充值或套餐管理。

## 2. 已确认的产品决策

1. 生成器允许用户切换多个真实模型，模型能力由服务端配置提供。
2. 点击生成后直接创建并执行任务，不显示费用确认弹窗。
3. 本期没有积分额度功能；界面只允许展示模型配置提供的预计消耗信息。
4. 第一张成功结果原位替换生成器占位节点。
5. 输出数量大于一时，其余图片在第一张右侧自动按网格排列。
6. 实现复用现有 Agent `generate_images` 操作链路，而不是另建一套前端直连流程。

## 3. 交互和视觉设计

### 3.1 生成器节点

图片生成器仍是正式画布节点。选中该节点时显示锚定面板；移动、缩放或平移画布时，面板跟随节点，但保持屏幕可读尺寸。面板接近视口边缘时翻转或限制在安全区。

生成器节点上方显示类型标识和名称，下方显示与节点关联的大尺寸输入面板。面板采用 Loomoon 的中性色视觉系统：白色主体、细边框、大圆角、轻阴影和清晰的黑色主操作，不复制 Lovart 商标或品牌资产。

### 3.2 输入面板

面板包含：

- 参考图入口和已选参考图缩略图；
- 多行提示词，默认提示“今天我们要创作什么”；
- 左下角合并设置入口，摘要格式为“质量 · 尺寸 · 数量”；
- 右下角模型选择器；
- 预计消耗展示位；
- 生成按钮。

提示词为空、模型不可用、配置不合法或正在提交时禁用生成按钮。提交中不得重复创建同一批次。

### 3.3 图像设置弹层

设置入口打开锚定弹层，结构按用户提供的参考图实现：

- 质量：自动、高、中、低；
- 尺寸：宽度和高度输入框，支持比例锁定；
- 宽高比：`1:1`、`3:2`、`2:3`、`4:3`、`3:4`、`9:16`；
- 高清预设：`1:1(2K)`、`16:9(2K)`、`9:16(2K)`、`16:9(4K)`、`9:16(4K)`；
- 自动尺寸：`auto`。

每个模型返回自身支持的质量、像素范围和宽高比。前端只展示当前模型可用的选项；切换模型导致配置失效时，优先映射到最接近的合法值，并明确更新摘要。

### 3.4 模型选择

模型列表不再硬编码在前端。服务端返回模型 ID、名称、说明、是否支持参考图、支持的质量和尺寸、预计消耗文案及可用状态。首批配置覆盖环境变量中已有的主模型、备用模型和草图模型。

不可用模型可隐藏；如果需要解释配置问题，则显示禁用项及原因。前端提交的 `modelId` 必须由服务端再次校验，不允许调用未配置模型。

## 4. 架构

### 4.1 模型能力目录

API 提供只读模型能力接口，返回可暴露给当前部署环境的图像模型。模型目录是生成参数校验的唯一事实来源，环境变量负责模型标识，代码配置负责能力和展示元数据。

### 4.2 可信直接提交

画布生成器通过专用 API 提交配置。服务端验证项目权限、生成器节点、模型能力、参考图、尺寸和输出数量后：

1. 创建 `generate_images` 操作记录；
2. 标记来源为 `canvas-generator`；
3. 在同一服务端事务边界内完成可信确认；
4. 交给现有本地生成执行器和并发队列；
5. 返回批次、任务和初始节点状态。

该路径不伪造聊天消息，也不依赖客户端提交“已确认”标志。只有经过权限校验的生成器端点可以触发直接确认。

### 4.3 Provider 调用

现有百炼客户端从固定单模型改为按已验证的 `modelId` 调用。请求根据模型能力映射质量、宽高、参考图和单图输出参数。一个输出对应一次可追踪任务，以便隔离失败、重试和记录 provider request ID。

### 4.4 状态和恢复

批次状态为：排队、生成中、部分失败、完成、失败、取消。任务状态独立记录。刷新后，项目读取接口合并画布节点、操作记录和生成历史，恢复尚未结束的批次状态。

右侧 Agent 活动流显示紧凑的“画布生成任务”卡片，包括模型、完成数量、总数量和失败状态，但不创建虚假的用户/助手对话轮次。

## 5. 数据模型

`GeneratorConfig` 增加或规范以下字段：

- `modelId`；
- `quality`；
- `width`、`height` 或自动尺寸；
- `aspectRatio`；
- `outputCount`；
- `referenceAssetUrls`；
- `status`；
- 当前 `batchId`；
- 可选的错误码。

生成操作记录增加：

- `source: "canvas-generator" | "agent"`；
- `generatorNodeId`；
- 完整、不可变的配置快照；
- 可选 `costEstimate`；
- 可选 `billingReservationId`。

费用字段本期保持空值，不执行余额校验或扣费。

## 6. 结果布局

任务提交后，生成器节点转为运行中占位状态，保留原位置、宽高、旋转和层级。

- 第一张成功结果原位替换生成器节点，并继承其主要几何属性；
- 后续结果位于第一张右侧；
- 两张结果使用单行排列；
- 四张结果使用两列网格；
- 间距使用画布域布局常量；
- 新图片不得覆盖已有节点，发生碰撞时整个结果网格向右寻找最近可用区域；
- 结果均保存 `sourceGeneratorId` 或等价来源关系，生成历史保留原配置。

部分失败时，成功图片正常落位，失败槽保留可重试状态。重试只创建失败输出，不重复生成成功项，也不改变已成功图片的位置。

## 7. 错误处理

- 模型不可用或参数非法：提交前由 API 返回字段级错误；
- 鉴权和越权：使用现有统一错误响应，不暴露资源存在性；
- 供应商限流、超时或不可用：映射到现有百炼错误码；
- 资产下载或持久化失败：任务不得标记成功；
- 部分失败：批次标记为部分失败并允许单项重试；
- 重复提交：通过批次幂等键防止重复任务；
- 页面刷新：从服务端状态恢复，不依赖内存中的前端定时器。

## 8. 测试与验收

### 8.1 单元和契约测试

- 模型能力目录和服务端 `modelId` 校验；
- 模型参数到百炼请求的映射；
- 设置弹层选项、模型切换后的配置归一化；
- 生成按钮禁用条件；
- 可信直接确认只允许生成器端点触发；
- 幂等提交、部分失败和只重试失败项；
- 第一张原位替换及多图网格布局；
- 状态恢复和来源关系。

### 8.2 集成验收

1. 创建图片生成器并输入提示词；
2. 切换两个不同真实模型并确认提交模型生效；
3. 上传参考图并完成一次图生图；
4. 使用自定义尺寸和一个高清预设完成生成；
5. 分别生成一张、两张和四张图片；
6. 验证第一张原位替换，其他图片无重叠排列；
7. 验证刷新期间任务和完成结果可恢复；
8. 模拟一个任务失败，验证部分成功和单项重试；
9. 验证资产使用 Loomoon 持久化 URL，而非供应商临时 URL；
10. 运行 Web、API 和共享包的测试、类型检查及构建。

## 9. 迁移和兼容

旧生成器节点缺失新字段时使用安全默认值；旧静态模型 ID 映射到服务端目录中的默认模型。现有 Agent 创意计划生成流程保持原确认语义，只有 `canvas-generator` 来源的专用端点采用可信直接确认。
