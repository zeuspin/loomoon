# Agent 对话布局设计

## 目标

修复长对话和图片任务将输入区推到视口外的问题，并用更接近 Lovart 的轻量内容流明确区分用户与 Agent。

## 布局

- `AgentSidebar` 和 `ThreadPrimitive.Root` 必须占满侧栏可用高度，并设置 `min-height: 0`。
- 侧栏标题固定在顶部。
- `ThreadPrimitive.Viewport` 是唯一的消息滚动容器。
- `ComposerPrimitive.Root` 固定在侧栏底部，不参与消息列表滚动。
- 输入区与消息区之间使用轻阴影和必要的结构分隔，不增加装饰性粗边框。

## 对话角色

### Agent

- 左对齐。
- 使用品牌 Agent 头像、名称与正文内容列。
- 普通 Agent 消息不使用背景气泡。
- 连续 Agent 消息仍保留角色标识，避免滚动定位后失去上下文。

### 用户

- 右对齐。
- 使用浅品牌色背景的小圆角气泡。
- 不显示头像，减少视觉噪声。
- 最大宽度不超过消息区的 78%。

### 工具与生成任务

- 作为 Agent 内容流的一部分左对齐。
- 保留结构化卡片，但降低阴影和背景对比。
- 图片结果不改变输入区的位置。

## 滚动行为

- 新消息和运行状态出现时，使用 assistant-ui Thread primitive 的自动滚动能力。
- 用户主动向上查看历史时，不强制抢回底部。
- 输入区在所有滚动位置始终可见。

## 交互和可访问性

- 输入框继续使用“消息内容”作为可访问名称。
- 空输入时发送按钮禁用。
- 发送中显示 Agent 处理中状态，不提供无法兑现的取消按钮。
- 键盘提示与上传参考图入口保留。

## 视觉约束

- Demo 保持白色浅色主题。
- 圆角只使用现有 2–4px 设计令牌。
- 所有颜色、阴影和结构线均来自设计令牌。
- `apps/web` 不直接依赖 assistant-ui，所有样式与对话组件继续封装在 `@loomoon/agent-ui`。

## 验收

- 在 1394×1216 视口中，存在多张生成图片时输入区仍在侧栏底部可见。
- Agent 消息显示左侧头像和名称，正文无气泡。
- 用户消息显示右侧浅品牌色气泡。
- 消息区可滚动，页面主体和输入区不随消息滚动。
- 既有发送、确认、图片选择、上传和工具结果行为无回归。
- 组件测试、Web 测试、类型检查和生产构建通过。
