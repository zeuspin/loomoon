# Loomoon 无限画布手势导航设计

日期：2026-07-27

## 1. 目标与范围

本规格改善 Loomoon 在 Mac 触控板、鼠标和 iPad 触屏上的无限画布导航，解决当前滚轮无条件缩放、触摸复用鼠标逻辑、画笔与对象拖动争夺输入等问题。

本阶段交付：

- 双指平移与以双指中心为锚点的捏合缩放。
- Mac 触控板和鼠标的滚轮平移、修饰键缩放。
- 根据当前工具分派单指输入。
- 从单指画笔安全升级到双指导航。
- 可独立测试的手势状态机及冲突回归测试。

本阶段不实现画布旋转、惯性滑行、橡皮筋边界或三指快捷手势。三指手势可能与 iPadOS 撤销、重做及剪贴操作冲突，因此不承载核心功能。

## 2. 输入优先级

输入按以下顺序决定所有权：

1. 两个有效触点出现时，双指导航拥有最高优先级。
2. 只有一个触点时，由当前画布工具决定行为。
3. 鼠标和触控板滚轮由滚轮分流规则处理，不进入触摸状态机。
4. HTML 输入框、下拉菜单、按钮和可编辑区域继续拥有自身输入，不触发画布手势。

画布对象不得自行推断触摸意图。手势识别器先确定所有权，再向现有画布控制器派发平移、缩放、框选、移动对象或绘制操作。

## 3. 单指行为矩阵

### 3.1 选择工具

- 单指或鼠标左键按住对象并拖动：移动该对象或当前多选对象。
- 单指或鼠标左键在空白处拖动：框选。
- 点击对象：沿用现有选择规则。
- 点击空白：沿用现有清空选择规则。

### 3.2 画笔工具

- Apple Pencil、鼠标左键和单指触摸均可绘制。
- 无论按下位置在空白还是对象上，底层对象都不接收选择或拖动事件。
- 画笔坐标始终转换为画布坐标，缩放和平移不能改变已采样点的位置。

### 3.3 小手工具

- 单指或鼠标左键在任意位置拖动均平移画布。
- 对象不响应选择、移动或打开操作。

### 3.4 其他工具

- 形状、文字和生成器等创建工具保留现有单指语义。
- 双指导航仍可临时覆盖这些工具；导航结束后恢复原工具，不隐式切换为选择工具。

## 4. 双指导航

双指导航同时支持平移和缩放，不把它们拆成互斥模式：

- 双指中心的屏幕位移直接转换为相机位移。
- 两指距离比例决定新缩放值。
- 缩放范围保持 `0.25` 至 `1.8`。
- 每一帧均保持手势起始时双指中心下方的画布坐标，映射到当前双指中心；因此平移和捏合可自然组合。
- 双指期间阻止浏览器默认滚动、页面缩放和 Konva 节点拖动。
- 不实现双指旋转；触点角度变化不改变画布角度。

手势识别基于触点标识而非数组顺序。任一触点移动时，从当前两个活动触点重新计算中心和距离，避免浏览器调整触点顺序造成跳变。

## 5. 画笔升级为双指导航

第二个触点落下时，正在进行的单指画笔必须先结束，再启动双指导航：

- 少于两个有效画布采样点的笔画视为无效并丢弃。
- 已有至少两个有效画布采样点的笔画立即提交，提交内容只包含第二指落下前的采样。
- 第二指落下本身不得成为笔画采样点。
- 双指导航结束后进入等待清空状态；必须等所有触点抬起，才允许开始下一次单指绘制。
- 从双指减少到单指时，剩余手指既不继续旧笔画，也不立即开始新笔画，避免产生尾线。

同一升级规则适用于从选择工具的对象移动、框选，以及创建工具的未完成手势进入双指导航：取消尚未提交的瞬时操作，导航结束后保留原工具。

## 6. Mac 触控板与鼠标

- 无修饰键的 `wheel`：使用 `deltaX` 和 `deltaY` 平移画布。
- `Ctrl + wheel`：按浏览器的触控板捏合约定，以事件指针位置为中心连续缩放。
- `Meta + wheel`：同样以事件指针位置为中心缩放，为鼠标用户提供明确快捷方式。
- 缩放使用连续增量，不再按滚轮方向应用固定 `0.08` 步长；需要归一化不同 `deltaMode`，并限制单帧变化，避免设备差异造成突跳。
- 滚轮处理与当前选择、画笔或创建工具无关，不移动对象，也不创建笔画。

## 7. 状态边界

新增纯手势状态，至少覆盖：

```ts
type CanvasGesture =
  | { kind: "idle" }
  | { kind: "single-pointer"; pointerId: number; owner: SinglePointerOwner }
  | {
      kind: "two-pointer-navigation";
      pointerIds: [number, number];
      startCenter: Point;
      startDistance: number;
      startCamera: Point;
      startScale: number;
      anchoredCanvasPoint: Point;
    }
  | { kind: "awaiting-all-pointers-up" };
```

手势状态只负责输入所有权、触点集合和相机变换参数。节点移动、框选和画笔提交继续由现有 Canvas 控制器及 React 状态负责，避免在两套状态中复制业务数据。

若第二指落下时两指距离接近零，则暂时只按中心位移平移；距离达到稳定阈值后才启用缩放，防止除零或异常放大。

## 8. 浏览器与渲染集成

- 画布容器设置 `touch-action: none`，只在画布交互区域阻止浏览器手势。
- 使用 Pointer Events 跟踪 `pointerId`、`pointerType` 和位置，并在手势持续期间捕获指针。
- Konva Stage 不再依靠 `draggable` 同时处理触摸导航；相机位置由统一手势输出更新。
- 单指命中信息在手势开始时确定。画笔和小手工具即使命中节点，也向控制器报告工具拥有输入，节点事件不得并行执行。
- 组件卸载、窗口失焦、`pointercancel` 或捕获丢失时清理活动触点并结束瞬时操作，避免画布停留在拖动状态。

## 9. 测试与验收

纯函数测试覆盖：

- 双指同向移动只改变相机位置。
- 双指距离变化围绕中心缩放，并保持锚点画布坐标稳定。
- 双指平移与缩放可在同一更新中组合。
- 缩放限制在 `0.25` 至 `1.8`。
- 第二指中断无效笔画时不创建路径。
- 第二指中断有效笔画时只提交已有采样。
- 双指减少到单指时进入等待清空状态，不产生尾线。
- 画笔工具命中对象时不移动或选择对象。
- 选择工具单指拖动对象仍移动当前选择。
- 小手工具单指命中对象时只移动相机。
- 普通滚轮平移，`Ctrl` 或 `Meta` 修饰滚轮缩放。
- `pointercancel` 和失焦能够复位状态。

人工验收设备至少包括：

- Mac 触控板：双指滚动、捏合、快速交替平移与缩放。
- Mac 鼠标：滚轮平移、`Command + wheel` 缩放、对象拖动和画笔绘制。
- iPad Safari：选择工具拖对象及框选、画笔单指绘制、绘制中加入第二指导航、双指结束后的防尾线。

## 10. 完成标准

- 导航手势不因当前工具或触点命中对象而误拖对象。
- 画笔工具下单指可以跨对象连续绘制，对象选择和位置保持不变。
- 单指升为双指时没有意外笔画、画布跳变或剩余手指尾线。
- 平移和缩放反馈与触点保持一比一，不等待手势结束才更新。
- 现有选择、框选、对象移动、形状、文字和生成器工具测试无回归。
