# Loomoon 扁平化视觉系统

## 目标

在不改变现有功能、布局和交互的前提下，将 Loomoon Demo 统一调整为克制的扁平视觉，并保持 Lovart 式三栏工作区结构。

## 已确认的视觉规则

- 普通控件使用 `2px` 圆角，容器、弹窗和媒体内容最大使用 `4px` 圆角。
- 状态点、头像等具有圆形语义的元素可以继续使用 `50%` 圆角。
- 不使用胶囊形按钮或装饰性大圆角。
- 允许阴影，但阴影应低对比、低扩散，只用于浮层、弹窗、菜单和需要表达悬浮关系的控件。
- 普通卡片不依靠阴影表达层级。
- 尽量不使用边框。边框仅用于面板结构分割、输入与焦点、画布选中区域、危险状态等功能性场景。
- 不使用装饰性渐变，品牌与状态表达使用纯色。
- 层级主要通过背景明度、留白、色块和轻阴影建立。

## 覆盖范围

- 登录页与登录表单
- 顶栏、工具栏、画布空状态与缩放控件
- Agent 消息、计划、确认、进度、错误与输入区
- 项目菜单与历史记录抽屉
- 局部重绘弹窗和选区

## 非目标

- 不调整页面布局、文案、交互流程或功能权限。
- 不调整 Konva 画布节点的数据结构和生成图片内容。
- 不引入新的 CSS 框架或组件库。

## 验收标准

1. 所有非圆形语义元素的圆角数值不超过 `4px`。
2. CSS 中不存在 `linear-gradient` 或其他装饰性渐变。
3. 登录卡片、消息卡片、计划卡片等普通内容容器不再使用装饰性边框。
4. 弹窗、菜单和悬浮工具条可以保留轻阴影，但不使用大范围、重颜色阴影。
5. 项目构建、类型检查与现有测试全部通过。
6. 在登录页和主工作台进行浏览器视觉检查，主要交互仍可正常使用。
