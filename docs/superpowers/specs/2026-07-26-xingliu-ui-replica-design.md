## 1. 目标

在保留 Loomoon 现有项目、Konva 画布、Agent Session/Run、生成确认、上传、历史、SSE 和 mock provider 的前提下，将 Web 前端重构为星流式产品体验。

复刻范围包括未登录首页、登录后首页、项目页、灵感详情、个人主页、会员与通知弹层、画布工具系统、画布右侧 Agent 对话系统，以及桌面、平板和移动端响应式布局。

“复刻”指布局、信息密度、交互结构和状态反馈与参考产品一致，不复制星流商标。产品继续使用 Loomoon 名称和品牌资产。

## 2. 实施原则

1. 保留真实领域能力，不新建一套脱离现有 API 的假画布或假 Agent。
2. 项目、认证、画布、Agent、图片生成和持久化继续接现有实现。
3. UGC、会员、通知、个人主页、视频生成和尚无后端支持的高级工具通过有类型的 mock repository 提供。
4. 所有可见按钮必须有反馈或状态变化，不保留装饰性死按钮。
5. 未登录用户可以滚动、查看页面内容、输入文字和观看自动提示词轮播；除此以外的所有点击操作都先要求登录。
6. 登录前发起的操作必须在登录成功后恢复，不丢失提示词、目标案例、目标路由或引用信息。
7. 不删除 Loomoon 现有生成成本确认机制。
8. 不新建分支，不推送代码。

## 3. 前端架构

```text
App
├─ AuthProvider
├─ IntentProvider
├─ AppRouter
│  ├─ HomePage
│  ├─ ProjectsPage
│  ├─ InspirationCaseOverlay
│  ├─ ProfilePage
│  └─ CanvasPage
└─ GlobalOverlays
   ├─ LoginDialog
   ├─ MembershipDialog
   ├─ NoticePanel
   └─ AboutMenu
```

### 3.1 AuthProvider

复用以下现有接口：

- `POST /api/v1/auth/login`
- `GET /api/v1/auth/me`
- `POST /api/v1/auth/logout`

登录方式保持邮箱和密码。登录弹层视觉采用桌面双栏、移动端单栏，但不实现微信扫码或第三方登录。

### 3.2 IntentProvider

统一保存登录前的待执行行为。Intent 至少包括：

```ts
type DeferredIntent =
  | { kind: "submit-prompt"; prompt: string; referenceCaseId?: string }
  | { kind: "open-route"; href: string }
  | { kind: "open-case"; caseId: string }
  | { kind: "remix-case"; caseId: string }
  | { kind: "open-overlay"; overlay: "membership" | "notices" | "about" };
```

受保护行为统一通过 `runProtectedIntent(intent, action)` 执行：

- 已登录：立即调用 `action`。
- 未登录：保存 intent 并打开登录弹层。
- 登录成功：消费一次 intent，执行对应动作。
- 用户关闭弹层或登录失败：保留页面输入，但不执行 intent。
- 主动点击“注册/登录”不创建 DeferredIntent，登录后停留原页面。

### 3.3 AppRouter

使用浏览器 History API，不新增第三方路由依赖。支持：

- `/`
- `/items`
- `/canvas?projectId=:projectId`
- `/profile`
- `/case/:caseId`

`/case/:caseId` 以覆盖首页的全屏详情层呈现，但保持可直接访问和前进/后退。

### 3.4 MockContentRepository

提供稳定、有类型的数据接口：

- 灵感分类、案例、作者、提示词、生成步骤和统计数据。
- 会员套餐。
- 通知列表。
- 个人主页的已发布和喜欢内容。
- 视频生成任务状态。
- 尚未实现的联网检索步骤。

页面组件只依赖 repository 接口，不直接导入散落的常量数组。

## 4. 首页

### 4.1 公共结构

- 左上 Loomoon Logo。
- 中央品牌标题、副标题、Agent 输入框。
- 快捷分类：海报宣传、品牌设计、风格插画、电商营销、视频与分镜。
- 灵感发现分类栏和 UGC 瀑布流。

输入框为空且未聚焦时，提示词按固定间隔纵向滚动。用户聚焦、输入或系统启用 `prefers-reduced-motion` 时停止轮播。

### 4.2 未登录状态

- 右上显示会员中心和注册/登录。
- 不显示私人项目列表。
- 允许输入、滚动和观看提示词轮播。
- 点击快捷分类、附件、输入能力、左侧导航、会员、作品卡片、喜欢、分享、做同款等任何交互均先打开登录弹层。
- 点击发送时缓存完整提示词；登录成功后创建项目、创建 Agent Session、发送提示词并进入画布。
- 点击案例时缓存案例 ID；登录成功后打开对应详情。

### 4.3 登录状态

- 右上显示通知、升级/积分和头像。
- Agent 区与灵感区之间插入“最近项目”。
- 最近项目第一张为新建项目，其余来自真实项目 API。
- 点击项目进入真实画布。
- 首页发送提示词时创建项目、创建 Session、发送消息并进入画布。

## 5. 项目页

- 桌面使用卡片网格。
- 移动端使用单列大卡片。
- 卡片显示封面、名称和更新时间。
- 新建、进入、重命名和删除使用真实项目 API。
- 删除保留二次确认。
- 删除按钮只在悬停、键盘聚焦或移动端操作区显示。

## 6. 灵感发现与案例详情

### 6.1 灵感列表

- 分类包括全部、品牌设计、海报与广告、插画、UI 设计、角色设计、影片与分镜、产品设计和建筑设计。
- 桌面使用多列卡片网格。
- 移动端分类横向滚动，作品使用两列瀑布流。
- 卡片显示作品、作者、浏览量和喜欢数。

### 6.2 案例详情

真实参考交互：

- 点击作品进入 `/case/:caseId`。
- 全屏详情层覆盖首页。
- 左侧为同一案例结果缩略图。
- 中间为选中结果大图。
- 右侧为作者、浏览量、喜欢数、分享、提示词、模型、结果名称和生成结果。
- 顶部包含查看回放、做同款和关闭。

实现要求：

- 缩略图切换当前结果。
- 查看回放根据 mock 时间线逐步高亮缩略图和右侧步骤。
- 做同款携带案例提示词、参考图和案例 ID。
- 登录后执行做同款时创建项目、注册参考图并把引用上下文提交给现有 Agent。
- 移动端使用大图、横向缩略图和信息抽屉的纵向结构。

## 7. 个人主页与全局弹层

### 7.1 个人主页

- 展示头像、昵称和分享主页。
- 支持已发布、我的喜欢两个标签。
- 首版由 mock repository 提供内容。
- 未登录访问先打开登录弹层。

### 7.2 登录弹层

- 桌面双栏：左侧 Loomoon 品牌视觉，右侧邮箱和密码表单。
- 移动端单栏。
- 提供加载、错误、禁用和重试状态。
- 提供用户协议和隐私政策入口。
- 支持 Esc、遮罩关闭、焦点限制和关闭后的焦点恢复。

### 7.3 会员弹层

复原入门版、基础版、专业版和旗舰版四档套餐及月付/年付切换。数据来自 mock repository，购买按钮显示清晰的 mock 反馈，不进入真实支付。

### 7.4 通知与关于

- 通知使用右侧抽屉和 mock 列表。
- 关于菜单包含协议、隐私、客服、招聘和社交入口。

## 8. 画布页面

### 8.1 页面结构

- 顶部项目栏。
- 左侧悬浮工具栏。
- 中央 Konva 画布。
- 画布缩放控件。
- 右侧 Agent 面板。
- 左下图层和积分入口。

真实 Konva 节点、选择、拖动、缩放、撤销、重做、上传、保存和 SSE 更新保持不变。

### 8.2 左侧工具

| 工具 | 行为 | 实现级别 |
| --- | --- | --- |
| 选择 | 点击、拖动、框选、Shift 多选 | 真实 |
| 新增 | 上传图片、上传视频、智能画板 | 图片真实；视频和智能画板部分 mock |
| 形状 | 矩形、圆形、三角形、星形、形状文本、对话框、左右箭头 | 本地真实 |
| 文本 | 在当前视口添加并编辑文本 | 真实 |
| 绘制 | 铅笔、钢笔 | 铅笔真实；钢笔可编辑路径 mock |
| 图像生成器 | 打开独立生成面板 | 接真实 Agent |
| 视频生成器 | 打开视频生成面板 | 完整 mock 状态流 |

### 8.3 智能画板

- 可选中、移动和调整尺寸。
- 显示名称与宽高。
- 支持常用比例和自定义尺寸。
- 可容纳图片、文本和形状。
- 首版嵌套关系保存到现有画布文档，不引入独立布局引擎。

### 8.4 图像生成器面板

包括：

- 提示词。
- 模型选择。
- 参考图。
- 风格/模式。
- 宽高比。
- 生成数量。
- 积分消耗提示。
- 生成按钮。

提交链路必须通过现有 `Agent Session → Run → Confirmation → Generation`。

### 8.5 对象上下文

所有可选对象显示蓝色选择边框、尺寸控制点和对象名称。

- 图片：裁剪、适应、下载、区域编辑、作为参考。
- 文本：内容、字体、字号、字重、对齐、颜色。
- 形状：填充、描边、圆角、透明度。
- 多选：对齐、分布、组合、批量交给 Agent。
- 通用：复制、删除、锁定、层级。

单选和多选对象同步进入 Agent 引用上下文，多选最多 8 个对象。

### 8.6 画布辅助能力

- 画布平移、缩放和鼠标中心缩放。
- 图层面板。
- 撤销、重做。
- 自动保存、冲突重连和保存状态。
- 项目名称编辑。
- Agent 面板折叠与展开。

## 9. Agent 对话系统

### 9.1 会话顶部

- 会话标题。
- 新建对话。
- 可搜索的历史对话。
- 分享对话。
- 已生成文件列表。
- 收起 Agent 面板。

新建对话在同一项目创建新的 Agent Session，不清空画布。历史列表切换后恢复对应消息。分享首版 mock。文件列表展示生成结果缩略图和名称，并能定位画布对象。

### 9.2 消息类型

- 右对齐用户消息。
- 日期分隔。
- Agent 正文。
- 文件和画布对象引用块。
- 模型标签。
- 图片或视频结果。
- 规划、等待确认、执行中、部分成功、完成、失败和取消状态。
- 完成后的点赞和点踩。
- 失败后的原因、成功结果保留和单项重试。

消息数据来自 `PersistentAgentMessage` 和 `PersistentAgentRun`，不能用独立前端假聊天替换。

### 9.3 Agent 与画布联动

- 画布选择同步为输入引用。
- 引用以可移除 Chip 展示。
- 消息结果与画布节点共享关联 ID。
- 点击消息或文件结果定位并选中画布节点。
- 占位节点与 Run 进度同步。
- 取消、失败、重试和完成同时更新消息与画布。
- 新建会话不删除画布资产。

### 9.4 输入区

- 多行自适应输入框。
- 附件上传。
- `@` 引用菜单。
- 联网开关。
- 模型偏好。
- 发送/停止。
- 已引用对象 Chip。

`@` 菜单支持搜索当前项目文件、查看更多资源和选择模型。

模型偏好支持：

- 自动选择开关。
- 图像/视频标签。
- 模型名称、说明、预计耗时和选中状态。

后端模型仍由 Loomoon 能力路由决定。前端展示选择不能绕过服务端模型白名单。

联网能力尚未接入真实工具时，使用明确标识的 mock 检索步骤。

### 9.5 计划与确认

保留以下真实流程：

```text
用户消息
→ Agent 规划
→ 展示方向、目标和预计数量
→ 等待确认
→ 执行任务
→ 消息与画布同步进度
→ 完成、部分失败、失败或取消
```

## 10. 响应式设计

正式断点：

- 桌面：`>= 1180px`
- 平板：`768px–1179px`
- 移动端：`< 768px`

### 10.1 首页和项目

- 移动端顶部为汉堡菜单、Logo 和头像/登录。
- Hero 标题分行，输入框占满内容宽度。
- 快捷分类换行。
- 最近项目使用单列大卡片。
- 灵感分类横向滚动。
- UGC 使用两列瀑布流。

### 10.2 移动画布

- 左侧工具栏变为底部横向工具坞。
- 二级工具使用底部抽屉。
- Agent 默认收起为底部入口。
- Agent 半屏用于输入和最新消息，全屏用于历史、文件与模型偏好。
- 抽屉使用拖动手柄切换高度。
- 键盘弹出时输入保持可见。
- 画布和 Agent 不同时因软键盘发生缩放。

## 11. 视觉系统

```yaml
artifact: 桌面优先、移动端完整适配的 AI 设计工作台
audience: 使用 Agent 完成视觉创作的普通用户和设计师

motion-intensity: 3/10
information-density: 首页 4/10，画布 8/10

```

- 页面背景：`#ffffff`
- 画布工作区：`#f4f5f6`
- 主文字：`#111111`
- 次级文字：`#8d9199`
- 边框：`#e2e3e5`，1px
- 系统中文字体栈
- 基础间距：4px；主要使用 8、12、16、24、32px
- 输入框和大弹层圆角：16–24px

- 胶囊按钮使用全圆角

- 动效：160–240ms ease-out
- 提示词轮播为纵向滑动
- 支持 `prefers-reduced-motion`

## 13. 完成标准

1. 首页、项目页、灵感详情、个人主页、会员弹层和画布达到参考截图的布局、层级和信息密度。
2. 登录前后首页有明确差异，登录后在 Agent 和灵感之间展示真实最近项目。
3. 未登录除输入、滚动和提示词轮播外的点击全部经过登录拦截。
4. 登录成功能恢复提示词提交、目标路由、案例详情和做同款意图。
5. 画布工具具有真实或明确 mock 的完整交互。
6. Agent 会话、消息、Run、确认、文件列表和画布引用关系工作正常。
7. 所有可见按钮有反馈。
8. mock 能力明确标识，不伪装成真实后端结果。
9. 桌面、平板和移动端目标视口全部可用。
10. 所有仓库验证命令通过。
