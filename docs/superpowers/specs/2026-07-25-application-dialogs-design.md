# Loomoon 应用内对话框设计

## 目标

用视觉一致、可访问、跨浏览器的应用内对话框替换 `window.prompt` 和
`window.confirm`，使项目管理和文字编辑可在 Chrome、Edge及当前内置浏览器中验证。

## 范围

- 新建项目：输入名称，默认值为“未命名项目”。
- 重命名项目：预填当前项目名称。
- 删除项目：展示项目名称和不可撤销说明，使用危险操作按钮。
- 编辑文字节点：预填当前文字内容。

## 组件边界

在 `@loomoon/ui` 中提供通用 `Dialog`：

- `Dialog` 负责遮罩、焦点、Esc、标题、说明和操作区；
- `DialogField` 负责标签、输入框和校验错误；
- 业务状态与提交逻辑仍留在 `apps/web`；
- 对话框不直接调用项目 API 或操作画布。

## 交互

- 打开后自动聚焦输入框，并选中已有文本。
- Enter 提交输入型对话框；空白值不提交并显示错误。
- Esc 或“取消”关闭，不产生业务写操作。
- 提交时禁用按钮，API 错误在对话框内显示。
- 删除操作必须点击明确的“删除项目”按钮。
- 遮罩点击不关闭，避免误触丢失输入。

## 视觉

- 白色内容面板、轻遮罩、4px 圆角、轻阴影。
- 只使用设计令牌，不添加 Lovart 品牌素材。
- 普通主按钮使用品牌色；删除按钮使用危险色。
- 面板宽度约 400px，小屏不超出可视区域。

## 验收

- 源码不再使用 `window.prompt` 或 `window.confirm`。
- 四类操作均可通过应用内对话框完成。
- 取消和 Esc 不产生写操作。
- 空项目名、空文字显示可理解错误。
- 当前内置浏览器点击“新建”不再出现控制台错误。
- 项目创建、重命名、二次确认删除和文字编辑刷新后保持。
