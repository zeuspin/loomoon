# Creoor 服装设计 Agent 无限画布工作台设计

## 1. 目标

Creoor 首先服务服装设计师与服装品牌团队。首轮原型聚焦项目工作台，通过 Agent 对话理解、询问和澄清用户意图，并以无限画布承载图片、文字、笔迹及生成结果。

首轮原型放在仓库根目录的独立 `creoor/` 前端项目中。后端请求和数据全部使用 Mock，优先验证视觉、交互、画布编辑和 Agent 上下文体验。主页不在首轮精细设计范围内，只保留必要的返回入口。

支持桌面 Web 与 iPad 横屏。Apple Pencil 首轮完成事件与输入模式兼容，压感、倾角等高级笔刷表现作为渐进增强。

## 2. 核心原则

- 画布优先：工作台背景即无限画布，功能面板悬浮于画布之上。
- Agent 可见：Agent 默认位于右侧，但与其他主面板一样可以拖动、吸附、悬浮与收起。
- 上下文显式：Agent 不自动读取整张画布，用户必须显式添加图片、对象或选区。
- 服装专业化：图片识别与操作优先覆盖服装、面料、纹样、模特和商品视觉流程。
- 视觉统一：所有组件通过主题 Token 引用视觉值，不允许散落未经批准的颜色、字号、阴影或层级数值。
- 跨输入设备：鼠标、键盘、触控和 Apple Pencil 使用同一行为模型，并针对触控目标和手势冲突做适配。

## 3. 工作台空间结构

默认布局为：

- 用户与项目卡片位于左上角。
- 创作工具栏紧贴左侧屏幕边缘。
- 小地图、网格吸附、图层、快捷键和缩放工具位于左下角。
- Agent 对话面板位于右侧。
- 中间区域保持为尽可能完整的无限画布。

默认结构借鉴 Miora 的全屏点阵画布、轻量悬浮层和边缘控制，但将 Agent 的信息重心放在右侧。

## 4. 可编排主面板

以下四个区域统一使用 `DockablePanel` 行为模型：

1. 用户与项目卡片。
2. 创作工具栏。
3. 画布辅助工具。
4. Agent 面板。

每个面板支持六种状态：

- `docked`：吸附在屏幕边缘。
- `floating`：悬浮于画布之上。
- `collapsed`：收起为边缘图标或短胶囊。
- `peek`：点击或触碰后临时展开。
- `pinned`：固定展开，点击画布空白不会收起。
- `dragging`：拖动中并显示吸附预览。

交互规则：

- 面板可以拖至任意位置，靠近上下左右边缘时显示吸附预览。
- 面板吸附后与屏幕边缘融合，减少外侧圆角和阴影，强化内侧边界。
- 面板悬浮时使用完整圆角、柔和阴影与适量背景模糊。
- 临时展开的面板在点击画布空白后恢复收起；固定展开面板不受影响。
- 面板自动避让其他已吸附面板，不允许完全重叠。
- Agent 面板支持拖拽调整宽度。
- iPad 使用明确的拖动抓手，避免与画布平移和 Apple Pencil 绘制冲突。
- 提供恢复默认布局。

布局分别保存桌面与 iPad 两套设备配置。同一设备默认跨项目复用，项目允许保存覆盖配置。

## 5. 工具栏与二级工具层

工具栏支持紧凑与展开两种密度：

- 紧凑状态只显示图标。
- 展开状态显示动态图标、中文名称和键盘快捷键。

点击具体工具后打开独立的 DOM 二级浮层。例如画笔工具显示粗细、颜色、透明度和预设。二级浮层默认锚定当前工具，也可以拖离并成为独立浮动面板。

动态图标优先使用 MIT 许可的 Lucide Animated，缺失图标回退至同风格 Lucide。图标默认静态，仅在悬停、触碰、激活或状态变化时播放一次。生成、上传、语音录制等持续状态允许循环。系统开启 reduced-motion 时退化为静态或必要淡入淡出。

## 6. 主题与视觉规范

主题使用四层引用链：

`基础 Token → 语义 Token → 组件 Token → 状态/动效 Token`

### 6.1 基础 Token

包括品牌色、灰阶、字体族、字重、字号、行高、间距、尺寸、圆角、边框宽度、阴影、模糊、透明度、层级、动画时长和曲线。

字体建议：

- 中文：Noto Sans SC 或思源黑体。
- 英文和数字：Inter。
- UI 正文默认 14px，辅助文字 12px，按钮与工具项 13–14px，面板标题 16px。
- 桌面触控目标不小于 36px，iPad 触控目标不小于 44px。

### 6.2 语义 Token

示例包括：

- `surface.canvas`
- `surface.floating`
- `text.primary`
- `text.muted`
- `border.subtle`
- `border.focus`
- `action.primary`
- `status.warning`

### 6.3 组件 Token

示例包括：

- `toolbar.docked.background`
- `agent.floating.shadow`
- `imageMenu.radius`
- `composer.reference.selectedBorder`

### 6.4 状态与动效 Token

覆盖 `docked`、`floating`、`collapsed`、`expanded`、`active`、`disabled`、`dragging` 和 `generating`。

视觉规则：

- 画布背景保持低对比度，点阵和网格不与作品争夺注意力。
- 是否显示背景、边框、阴影和模糊由组件 Token 控制。
- 首轮实现浅色主题，并为深色和高对比度主题保留完整语义结构。
- 面板展开时长建议为 180–240ms，吸附使用轻微弹性反馈。
- reduced-motion 关闭位移和弹性，仅保留必要淡入淡出。
- 颜色必须满足可读性要求，选中、错误和生成状态不能只依赖颜色表达。
- 开发环境检查未经批准的颜色值、字号、阴影和 `z-index`，避免视觉常量散落。

## 7. 无限画布技术架构

使用 React、Konva.js 与 `react-konva` 的混合架构：

- Konva 负责图片、文字、笔迹、选区、Transformer、辅助线、框选和导出。
- React DOM 负责四个主面板、图片操作菜单、Agent、二级工具层、表单、Tooltip 和弹窗。
- 统一坐标转换服务维护画布坐标与屏幕坐标的映射，使 DOM 浮层可以跟随画布节点。
- React 状态是文档和图层数据的唯一事实来源，Konva 负责渲染和交互，不直接作为持久化数据源。

### 7.1 Konva 渲染层

保持 3–4 个固定渲染层：

1. 背景层：点阵、网格和画布背景。
2. 内容层：图片、文字、笔迹和用户逻辑图层。
3. 交互层：选框、Transformer、吸附线和拖拽预览。
4. 临时层：正在绘制或高频拖动的对象；交互结束后归还内容层。

用户图层不与 Konva Layer 一一对应。用户可以创建任意数量的图片、文字、分组和逻辑图层，它们作为内容层内的节点与 Group，通过顺序数据控制层级。

### 7.2 吸附

支持：

- 网格吸附。
- 画布边缘吸附。
- 对象边缘和中心点吸附。
- 水平与垂直参考线。
- 旋转角度吸附。
- 吸附开关、网格尺寸和吸附强度。

吸附阈值按屏幕像素计算，避免随画布缩放改变手感。

### 7.3 输入设备

- 鼠标支持滚轮缩放、拖动、框选和快捷键。
- iPad 支持双指缩放和平移，手势逻辑基于 Konva 触控事件自行计算。
- Apple Pencil 通过原生 Pointer Events 捕获压力、倾角和笔型信息，再交给 Konva 渲染。
- 画笔首轮使用 `Konva.Line` 保存可编辑矢量笔迹；大量笔迹时可以合并到离屏 Canvas。

## 8. 图片识别与智能操作

每张图片导入后进行离线视觉识别，并允许同时命中多个标签。

### 8.1 标签体系

- 内容主体：模特、服装、鞋履、箱包、配饰、面料、纹样。
- 图像形态：写真、商品图、线稿、款式图、平铺图、随手拍、局部细节、拼贴板。
- 视觉属性：正面、侧面、背面、棚拍、户外、纯色、印花、人物、静物、完整、局部。
- 质量状态：低清、背景杂乱、透视变形、光线不均、遮挡、文字水印。

### 8.2 操作体系

通用操作包括高清、裁剪、扩图、去背景、擦除、改字、拆分、矢量化、调整视角、反推提示词、重新生成和添加到对话。

服装专业操作包括换款、改版型、换面料、换纹样、改配色、系列延展、虚拟试穿、生成正侧背、款式图和工艺拆解。

场景操作包括：

- 纹样：四方连续、修改画风、提取元素、生成配色组。
- 写真：重打光、换服装、换图案、换模特、换姿势、换场景。
- 线稿：真实渲染、补全结构、生成面料表现、生成商品图。
- 商品图：转线稿、生成电商主图、细节图、场景图、宣传海报。
- 随手拍：校正透视、清理背景、棚拍化、识别单品、生成搭配。
- 面料：无缝化、材质增强、颜色替换、应用到服装、生成近景细节。

单选时显示通用能力与所有命中标签的专属能力。多选时默认显示所有选中图片均可执行的能力交集。“全部”视图展示完整能力，并标明适用图片数量。无法执行的图片不会被静默跳过，用户需要确认执行范围。

## 9. 画布选择与 Agent 上下文

画布支持点击、框选、多选、画笔圈选、划线批注和区域截图。

选择完成后显示上下文工具条，提供：

- 添加到 Agent 参考图。
- 生成带批注截图并添加到 Agent。
- 对齐、等距分布、分组和调整图层。
- 批量执行图片操作。
- 仅让 Agent 分析选区，不产生新内容。

Agent 输入框顶部显示可横向滚动的参考图托盘。每张参考图包含缩略图、编号、短名称、来源和移除操作。

输入 `@` 打开图片选择器，支持以下引用形式：

- `@图1`
- `@红色连衣裙正面`
- `@当前选区`
- `@刚才圈选的袖口`
- `@图1的版型`
- `@图3的纹样`

引用时，输入框和画布同步高亮对应图片或局部区域。消息保存稳定对象 ID，不仅保存显示名称，因此重命名后引用仍然有效。

项目内的画布与历史记录共享，但每个会话拥有独立上下文。将对象加入另一会话时必须显式执行“添加到当前会话”。Agent 在意图不明确时优先提出一至三个澄清选项；需要比较视觉方向时才向画布生成候选结果。

## 10. 图库与历史记录

原“资产库”改名为“历史记录”。工作台同时提供以下图库：

- 模特。
- 服装。
- 鞋履。
- 箱包。
- 配饰。
- 面料。
- 纹样。

每类图库都区分用户私有图库与公共图库。用户可以把上传、生成或处理后的结果保存到自己的图库，也可以选用公共图库内容作为参考。

## 11. 伴随表单式生成器节点

生成器由两个绑定部分组成：

- Konva 生成占位节点：显示生成类型、输出尺寸、宽高比、空状态、进度和结果。
- React DOM 参数表单：显示参考图、选区、提示词、模型、比例、清晰度、技能、语音和提交操作。

交互规则：

- 表单默认位于节点下方，缩放和平移时同步跟随。
- 拖动节点时，两部分整体移动并参与网格、对象边缘与中心线吸附。
- 表单宽度至少与占位节点一致，同时设置最大宽度。
- 可视空间不足时，表单自动翻转至上方或左右侧，不得超出可视区域。
- 表单可以收起为短胶囊，也可以解除伴随成为独立浮动面板。
- 参数下拉菜单与选择器使用 DOM 浮层，不受 Konva 裁切或画布缩放影响。
- 点击画布空白收起临时参数层，但保留已输入内容。
- 复制生成器时复制参数与参考关系，不自动重复执行生成。

状态流转为：

`empty → configured → queued → generating → completed`

并支持 `paused`、`cancelled`、`failed`、`retrying` 和 `partial`。

生成过程中显示轻量动态反馈与阶段文字。成功后结果替换占位图，同时保留原始参数以便重新生成。失败后保留提示词、参考图和参数。

首轮实现图片生成器，并为视频、纹样和模特换装生成器预留基于配置的扩展接口。

## 12. Mock 数据与状态

Mock 服务模拟：

- 网络延迟。
- 正常结果。
- 空数据。
- 图片识别中。
- 生成中。
- 失败和重试。
- 部分结果。

图片识别返回固定 Mock 标签，前端使用真实规则计算操作能力交集。项目、会话、面板布局、用户图库和画布文档保存在浏览器本地，刷新后恢复。

Mock 接口与 UI 状态解耦。未来接入真实后端时保持接口契约，避免重写组件。

## 13. 错误与恢复

- 图片识别失败时在图片节点上提供重试。
- 生成失败时保留输入、引用和参数。
- 面板位置异常或移出视口时自动校正，并提供恢复默认布局。
- 引用对象被删除后，消息保留引用快照并标记原对象已删除。
- 不使用阻断整个画布的全屏错误页；错误尽量在原位置反馈。

## 14. 首轮原型范围

首轮包含：

- 无限画布缩放、平移、框选、多选、基础对齐和图片节点。
- 四个可拖动、吸附、悬浮、收起和恢复布局的主面板。
- 可展开工具栏和画笔二级浮层。
- Agent 多会话、参考图托盘、`@` 引用和 Mock 澄清流程。
- 历史记录与七类服装专业图库。
- 图片多标签识别结果与上下文操作菜单。
- 图片生成器占位节点与伴随参数表单。
- 桌面和 iPad 横屏响应式布局。
- 浅色主题和完整主题 Token 架构。

首轮不包含：

- 真实登录与账号服务。
- 真实 AI、图片或视频生成。
- 实时多人协作。
- 完整主页和公开灵感库体验。
- Apple Pencil 高级压感笔刷调校。
- 深色与高对比度主题的完整视觉实现。

## 15. 验证标准

重点验证：

- 鼠标、键盘和触控交互。
- 面板吸附、悬浮、收起、临时展开和固定展开。
- 点击画布空白后的正确收起行为。
- 网格、边缘、中心点和旋转吸附。
- 用户图层排序、隐藏、锁定、分组与撤销重做。
- 多选图片操作交集。
- Agent 引用 ID 的稳定性。
- 生成器节点和伴随表单的同步定位。
- iPad 横屏响应式布局和双指手势。
- reduced-motion 动效降级。
- 主题 Token 泄漏检查。
- Mock 延迟、失败、重试和部分结果状态。
