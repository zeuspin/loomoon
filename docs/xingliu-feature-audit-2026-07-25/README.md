# 星流功能与交互盘点

盘点日期：2026-07-25  
目标站点：https://www.xingliu.art/

## 范围与限制

本次使用已登录的 Chrome 会话，对可见主功能、核心页面和关键弹层做了只读盘点。
为避免修改账号数据，没有执行生成任务、发布作品、分享主页、购买会员、删除项目或上传文件。
因此，涉及任务提交后的完整生命周期、支付结果页和发布结果页，仅能基于现有页面入口判断，不能视为已完成端到端验证。

## 信息架构

左侧全局导航保持固定：

1. 新建：圆形“+”按钮，用于创建新项目。
2. 首页：进入 Agent 对话式创作首页。
3. 项目：浏览、新建和重新进入已有项目。
4. 个人主页：管理已发布作品和喜欢的作品，并可分享主页。
5. 帮助/关于：协议、隐私、客服、招聘和社交媒体入口。

右上全局区域：

- 返回星流 Beta。
- 通知中心。
- 会员升级与当前积分余额。
- 当前登录用户头像。

## 1. Agent 创作首页

截图：[01-home.png](./01-home.png)

核心交互：

- 中央为自然语言需求输入区，用户用一句话描述设计目标。
- 支持添加附件。
- 输入区右侧有联网/全局知识类入口和扩展能力入口。
- 未输入内容时，发送按钮处于禁用状态。
- 提供任务快捷分类：海报宣传、品牌设计、风格插画、电商营销、视频与分镜。
- 下方展示最近项目，可从首页快速恢复历史工作。

交互模型：

1. 用户输入目标或选择快捷分类。
2. 可附加参考素材或开启辅助能力。
3. 提交后进入项目画布。
4. Agent 在画布右侧持续给出生成结果和说明。

## 2. 项目页

截图：[02-items.png](./02-items.png)

核心交互：

- “新建项目”卡片是创建入口。
- 已有项目以卡片网格展示，包含预览图、项目名和更新时间。
- 点击项目卡片可进入对应画布继续编辑。
- 当前截图中的项目名称均为“未命名”，说明系统允许项目在未重命名状态下持续保存。

## 3. 画布编辑器

截图：[03-canvas-overview.png](./03-canvas-overview.png)

整体结构：

- 顶部左侧：返回/品牌入口与项目名称。
- 中间：无限画布或大画布工作区。
- 左侧悬浮工具栏：选择、添加/框架、形状、文本、绘制，以及图片/视频素材类工具。
- 顶部中间：缩放比例与加减缩放。
- 右侧：Agent 会话与当前生成结果预览。
- 左下：图层入口和积分余额。

画布能力：

- 画布可同时放置多张图片并形成视觉排版。
- 选中工具用于对象选择、移动和后续编辑。
- 可添加容器/画板、基础形状、文本和手绘内容。
- 可继续导入或生成图片、视频素材。
- 缩放控制支持查看大范围画布或局部细节。

Agent 面板：

- 顶部显示当前任务标题和结果预览。
- 结果区提供添加/继续处理、历史/版本、分享、复制/导出、展开等图标入口。
- Agent 会说明任务完成状态和生成内容。
- 用户可以点赞或点踩结果。
- 底部输入框支持继续提出修改要求。
- 支持附件、@ 引用、联网/知识和扩展能力。
- 发送按钮在没有输入时禁用。

推断出的协作方式：

1. Agent 生成的多个方案直接落到画布。
2. 用户既可以在画布中手动排版，也可以在右侧继续用语言要求修改。
3. 右侧结果卡与画布对象关联，形成“对话生成 + 可视化编辑”的双轨工作流。
