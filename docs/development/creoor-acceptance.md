# Creoor 原型验收基线

机器可读矩阵位于 `creoor-acceptance.json`，当前包含 21 个父需求与 92 个原子条款。开发阶段使用 `node scripts/check-creoor-acceptance.mjs --phase=plan`；发布阶段由受保护环境运行 `--phase=release`。

本轮交付门槛是：两条黄金路径可在真实浏览器完成、固定桌面与 iPad 横屏 viewport 无阻断布局问题、交互截图完成设计 QA、无未处理的 P0/P1/P2。真实 iPad/Pencil、五名服装设计师研究与受保护签名属于用户验收及发布门禁，不会被本地模拟冒充为通过。

## 固定视口

- 1280×720
- 1440×900
- 1920×1080
- 1194×834
- 1366×1024

## 黄金路径

1. 导入服装图 → 演示识别/修正标签 → 显式加入 Agent → 澄清 → 换面料/纹样 → 派生结果 → 保存图库 → 导出。
2. 画笔/套索批注 → 冻结截图 → 结构化 `@` 引用 → 发送 → 刷新恢复。
