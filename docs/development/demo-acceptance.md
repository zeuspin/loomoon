# Loomoon 本地 Demo 验收清单

## 零费用完整页面验收

先停止正在运行的开发服务，然后执行：

```powershell
pnpm dev:mock
```

该模式保留完整的登录、项目、Agent 确认、四图任务、图片修改、区域修改、历史和
SSE 流程，但图片由 Mock Provider 生成，不调用付费百炼图片接口。API
`/api/v1/health/ready` 的 `provider` 字段应为 `mock`。

使用真实百炼时执行 `pnpm dev`；此时 `provider` 为 `bailian`。

## 启动门槛

- `pnpm env:check` 成功且不输出 API Key；
- `pnpm test`、`pnpm typecheck`、`pnpm build` 成功；
- API 健康检查返回 `{"status":"ok","service":"api"}`；
- Web 可通过 `http://localhost:5173` 访问。

## 垂直闭环

1. 使用 `demo@loomoon.local / loomoon-demo` 登录，刷新后会话保持；
2. 空白项目能自动创建并在刷新后恢复；
3. 提交创作需求后，Agent 返回恰好两个方向；
4. 确认前只创建四个画布占位，不调用图片模型；
5. 用户明确确认后生成四张图，并按两个方向布局；
6. 图片保存到 `.local-data/assets/`，不依赖百炼临时 URL；
7. 单击与 Shift 多选图片后，输入区显示选择快照；
8. “比较/推荐”只调用多模态分析，不创建图片；
9. “修改”先展示目标数与摘要，确认后才执行；
10. 修改结果保留原图、记录 `sourceNodeIds` 并放在来源旁边；
11. 拖动画布节点后自动保存，刷新可恢复；
12. 撤销、重做、缩放、平移、原图下载和画布导出可用。
13. 新建、切换、重命名和二次确认删除项目可用；
14. 第二账号不能访问第一账号的项目；
15. 参考图通过格式、大小和 Magic Bytes 校验后进入画布；
16. 区域修改保存原图像素 bbox，付费调用前必须确认；
17. 生成历史独立于画布节点，历史资产可重新加入；
18. 失败任务可单独重试，成功项不重复生成。

## 费用边界

- 发送需求与图片比较会调用百炼大语言/多模态模型；
- “确认并生成 4 张候选图”会创建四次图片生成；
- 图片修改按选中图片数量创建任务；
- 所有付费图片操作都必须通过界面确认按钮触发。
