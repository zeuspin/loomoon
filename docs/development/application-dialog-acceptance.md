# 应用内对话框验收

## 视觉与交互约定

- 新建、重命名、删除项目以及画布文本编辑统一使用应用内对话框，不使用 `window.prompt` 或 `window.confirm`。
- 对话框沿用浅色视觉系统：白色表面、4px 小圆角、轻阴影，仅在功能分隔或输入焦点处使用边框。
- 新建与重命名支持自动聚焦、Enter 提交、Esc 取消和空名称行内错误。
- 删除使用危险操作样式，明确展示项目名称与不可恢复提示；取消不会修改项目。
